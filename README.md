# 학급 소통함 (학급특색활동 아이디어 + 진로진학 상담 사전 설문)

학생용 주소: https://kyunhong.github.io/206/

- **학급특색활동 아이디어** (`#ideas`): 학생들이 활동을 제안하고 공감을 누릅니다. 친구들에게는 익명으로 보이고, 이름은 선생님 시트에만 저장됩니다.
- **진로진학 상담 사전 설문** (`#counsel`): 번호, 이름, 고민 분야, 희망 진로, 고민 내용을 받습니다. 학생 화면에는 아무것도 다시 보여 주지 않고, 선생님 시트에만 저장됩니다.

```
학생 휴대폰 ──▶ GitHub Pages(화면) ──▶ Apps Script ──▶ 구글 시트
```

## 파일 구성

| 파일 | 설명 | 고친 뒤 반영 방법 |
|---|---|---|
| `index.html` | 화면 문구, 입력 칸, 화면 제목(`data-title`) | git push |
| `app.js` | 화면 동작 | git push |
| `style.css` | 디자인 | git push |
| `config.js` | Apps Script 주소 | git push |
| `apps-script/Code.gs` | 서버 코드 (핵심 역량·고민 분야 목록, 글자 수 제한, 시트 구조) | Apps Script 편집기에 붙여넣기 → 새 버전 배포 |

## 화면 고치기 (git push)

```bash
cd "C:\Users\user\Desktop\코딩\학급특색활동\206"
git add -A
git commit -m "수정 내용"
git push
```

1~2분 뒤 사이트에 반영됩니다.

## 서버 코드 고치기 (Apps Script)

1. `apps-script/Code.gs`의 내용 전체를 Apps Script 편집기에 붙여넣고 저장합니다.
2. 함수 선택 칸에서 `setup`을 고르고 ▶ 실행을 누릅니다. 새로 생긴 시트나 열이 추가됩니다.
3. **배포 → 배포 관리 → ✏️ 편집 → 버전: 새 버전 → 배포**를 누릅니다. ('새 배포'를 누르면 주소가 바뀌니 주의하세요.)
4. 이 폴더에도 같은 내용으로 커밋해 둡니다.

## 구글 시트에서 관리하기

| 탭 | 내용 |
|---|---|
| `아이디어` | 제안자 이름 확인, **숨김** 체크로 학생 화면에서 숨기기, 행 삭제 |
| `진학상담` | 번호·이름·고민 내용 확인, **처리 상태**(접수 / 상담 예정 / 완료), 메모 |
| `설정` | B1 학급 이름(첫 화면 제목), B2 아이디어 제안 받기, B3 상담 접수 받기 |

- `아이디어` 탭 맨 오른쪽의 숨겨진 **작성자 키** 열과 숨겨진 `공감` 탭은 지우거나 고치지 마세요.

## 주의

- 이 저장소는 **공개**입니다. 학생 명단이나 시트에서 내려받은 엑셀·CSV 파일을 이 폴더에 두지 마세요. (`.gitignore`로 막아 두었지만, 다른 형식은 막히지 않습니다.)
- 학생 데이터는 구글 시트에만 있습니다. 백업이 필요하면 시트에서 **파일 → 사본 만들기**를 이용하세요.
